## Overall assessment
* Every individual building block (utility routing, priority buffers, aggregation under low bandwidth,
  semantic dedup, CRDT merge, HLL, threshold event detection, replicas, commitments) has prior art.
* The candidate distinction is the **specific coupling**: a utility/pressure-proposed representation change
  that commits only when a deterministic per-event-type invariant check on the *concrete reduced
  representation* passes; partitioning into never-evicted protected state vs bounded duplicate-insensitive
  sketches with lattice merge; and promotion of sketch-derived aggregates into a protected event whose id
  is a deterministic function of (rule, cell). Inventive step over #4 + #6 + #7 + #9 + #11 + #19 is the main
  risk (see `SIMULATED_FER.md`).
